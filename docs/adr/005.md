# 005 — Local terminal experience

Status — accepted

The user selected a terminal running directly on macOS with locally installed CLI tools and an Oh My Zsh experience. The initial tool list is kubectl, Docker CLI, Devbox and fzf. Colima is optional when a local container engine is desired.

The shell role owns managed Zsh settings and completion integration. Platform adapters own tool installation. Oh My Zsh currently clones the upstream default branch; pinning a reviewed revision remains a reproducibility follow-up and preserve existing installations. Integration into an existing `.zshrc` requires a preview, verified backup and explicit approval. The user selected the `agnoster` Oh My Zsh theme. Plugin choices remain open.

The configuration example keeps features disabled during the architecture milestone. A later implementation adds typed shell configuration and capability mappings with tests before enabling installation. Connection credentials remain in user-managed stores outside version control.
